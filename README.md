**HouseLens**는 서울특별시 아파트 실거래가 및 거래량 데이터와 한국은행·통계청·한국부동산원의 거시경제 지표(금리, 물가, 매매가격지수)를 결합하여 다중선형회귀분석(OLS)을 수행하고, 실시간 **What-If 시나리오 시뮬레이션**을 제공하는 인터랙티브 웹 대시보드 프로젝트입니다.

📌 **Toy Project**

거시경제 지표를 활용하여 서울 아파트 거래량을 분석하고,
회귀분석 결과를 기반으로 다양한 경제 상황을 시뮬레이션할 수 있도록 구현한
개인 토이 프로젝트입니다.

본 프로젝트는 데이터 전처리, 시각화 그리고 사용자 중심의 대시보드 구현에 중점을 두었습니다.

## 📌 1. 프로젝트 배경 및 문제 제기 (Background & Objectives)

### 💡 문제 제기
- **아파트 거래량**은 부동산 시장의 분위기와 선행 방향성을 가장 빠르게 보여주는 핵심 지표입니다.
- 그러나 **기준금리 변화, 주택담보대출금리, 아파트 매매가격지수, 소비자물가지수** 등 다양한 거시경제 요인이 실제 아파트 거래량에 어떠한 크기와 방향으로 복합적인 영향을 미치는지 직관적으로 파악하기는 어렵습니다.

### 🎯 프로젝트 목표
1. **거시경제 지표와 아파트 거래량 간 정량적 규명:** VIF 검증 및 OLS 다중선형회귀분석을 통해 각 거시지표가 서울 아파트 매매 거래량에 미치는 영향 평가
2. **직관적인 와이드 화면 시각화 대시보드:** 화면에서 월별 트렌드, 지표 상관관계, 통계량을 한눈에 분석
3. **인터랙티브 시나리오 시뮬레이션:** 현재(2026년 5월) 거래량을 기준점으로 설정하고, 주담대금리 및 매매가격지수 변화에 따른 실질 예상 거래량 증감 시각화

- **대상 지역:** 서울특별시 전역
- **분석 기간:** 2020년 01월 ~ 2026년 05월 (총 77개월)
- **포괄 시기 특성:** 코로나19 유동성 확대 및 초저금리 시기 → 글로벌 통화긴축 금리 인상기 → 최근 시장 조정기 전반을 포함하여 거시 환경 변화 충격을 포괄적으로 분석

### 📌 핵심 변수 정의 및 전처리 방식

| 변수 분류 | 변수명 | 데이터 출처 | 전처리 방식 및 의미 |
| :---: | :--- | :---: | :--- |
| **종속변수 ($Y$)** | **아파트 매매 거래량** | 국토교통부 | 월별 서울시 전체 아파트 매매 계약 건수 합계 |
| **독립변수 ($X_1$)** | **기준금리 변화** | 한국은행 | 월별 전월 대비 변화량 (`.diff()`) |
| **독립변수 ($X_2$)** | **주택담보대출금리 변화** | 한국은행 | 월별 전월 대비 변화량 (`.diff()`) - 실질 조달 비용 충격 |
| **독립변수 ($X_3$)** | **아파트 매매가격지수 변화율** | 한국부동산원 | 전월 대비 가격지수 등락률 (`.pct_change()`) |

## 📈 4. 핵심 분석 결과 (Exploratory & Regression Analysis)

### ① 상관관계 및 다중공선성(VIF) 검증
- **상관분석 (Correlation Heatmap):** 주택담보대출금리가 상승할수록 아파트 거래량이 감소하는 음(-)의 상관관계 뚜렷 확인.
- **다중공선성 검증 (VIF):** 
  - 회귀분석 전 독립변수 간 다중공선성 평가 결과, 모든 독립변수의 **VIF 지수가 약 1.1 ~ 1.3 수준**(기준치 10 미만)으로 나타나 변수 간 중복 없이 독립성이 확보되었습니다.

### ② OLS 다중선형회귀분석 통계 요약

| 모형 통계량 | 결과값 | 의미 및 해석 |
| :--- | :---: | :--- |
| **결정계수 ($R^2$)** | `0.4310` | 거시경제 지표 변동이 월별 아파트 매매 거래량 분산의 약 43.1%를 설명 |
| **수정된 결정계수 (Adj. $R^2$)** | `0.3994` | 변수 개수를 보정한 설명력 |
| **모형 유의성 (Prob F-stat)** | `< 0.001` | $p < 0.001$로 회귀모형 전체가 통계적으로 매우 유의함 |

### ③ 독립변수별 회귀계수 및 해석

| 독립변수 | 회귀계수 (Coef) | P-Value | 통계적 유의성 | 실질 해석 |
| :--- | :---: | :---: | :---: | :--- |
| **주택담보대출금리 변화** | **-7,893.04** | **0.0010** | **유의 ($p < 0.01$)** | 주담대금리가 월별로 1%p 상승 시, 거래량은 평균 **약 7,893건 감소**하는 강한 하방 충격 |
| **아파트 매매가격지수 변화율** | **+221,258.56** | **< 0.0001** | **유의 ($p < 0.001$)** | 가격지수 상승률이 높을수록 시장 상승 기대감으로 거래 활성도가 높아지는 양의 관계 |
| **기준금리 변화** | -2,722.72 | 0.218 | 비유의 | 단기 월별 변동에서는 주담대금리가 직접 영향을 미쳐 기준금리 직접 효과는 통계적으로 비유의 |
| **소비자물가지수 변화율** | -160,865.74 | 0.375 | 비유의 | 물가 변동율은 부동산 거래량과 직접적인 단기 유의성이 확인되지 않음 |

## 🔮 5. 실시간 시나리오 시뮬레이션 (What-If Dashboard)

대시보드의 **[시나리오 분석]** 메뉴에서는 사용자가 슬라이더를 통해 주담대금리 및 아파트 매매가격지수 변화를 직접 가정하고 예상 거래량을 확인할 수 있습니다.

- **기준점 (Baseline):** 2026년 5월 실제 거래량 수치를 초기값으로 설정
- **산식 적용:** 
  $$\text{예상 거래량} = \text{현재 거래량} + (\Delta \text{주담대금리} \times \beta_{\text{주담대}}) + (\Delta \text{매매가격지수변화율} \times \beta_{\text{매매지수}})$$
- **제공 기능:** 현재 vs 예상 거래량 비교 바 차트, 게이지 차트(Gauge Chart), AI 시장 동향 리포트 자동 생성

## ⚠️ 6. 분석 한계점 (Limitations)

본 프로젝트는 거시경제 지표와 거래량 간 정량적 관계 규명에 집중하였으며, 보다 종합적인 시장 해석을 위해 다음 한계점을 참고하시기 바랍니다.

1. **정책 및 비계량 외부 이벤트 미반영:** 대출 규제(DSR, LTV), 정부 부동산 규제 완화/강화 정책, 부동산 세제 개편 등 비계량적 이벤트 요인은 모형에 포함되지 않았습니다.
2. **서울시 전체 집계 데이터 한계:** 서울 전역의 합계 데이터를 사용하여 강남권/비강남권, 상급지/비상급지 등 입지별 차별적 금리 민감도를 반영하지 않았습니다.
3. **장기 시차(Lag Effect) 미 반영:** 금리 및 거시 변수의 영향이 1~3개월 이후 나타나는 장기 시차 효과는 본 월별 동시 모형에서 고려되지 않았습니다.
4. **선형 관계 가정:** 실제 부동산 시장의 군집 심리 등 비선형 상호작용은 OLS 선형회귀 가정을 넘어설 수 있습니다.

## 🚀 7. 설치 및 실행 방법 (Installation & Running)

### 1) 저장소 클론 및 폴더 이동
```bash
git clone https://github.com/eunseowo/HouseLens.git
cd HouseLens
```

### 2) 가상환경 생성 및 패키지 설치
```bash
# 가상환경 생성 (권장)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

### 3) Streamlit 대시보드 실행
```bash
streamlit run app.py
```
> 브라우저가 자동 열리며 `http://localhost:8501`에서 대시보드를 확인할 수 있습니다.
